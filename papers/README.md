# Papers folder

This folder stores research PDFs and metadata for the coding-agent literature map.

## Files

- `paper_titles.txt`: curated list of target papers.
- `papers-manifest.csv`: fetch result (Found/Not Found/Skipped/Failed).
- `unresolved.txt`: papers not automatically downloaded.
- `pdfs/`: downloaded PDFs.

## Notes on completeness

Some items are pre-2026 but still foundational. Some references may not be arXiv-hosted and will need manual links from their official venue pages.
